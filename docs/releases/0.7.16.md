# Vahti 0.7.16 - An orb that stays visible

The orb has a non-Metal drawing when GPU rendering is unavailable.

- The menu shows the installed version, build and orb renderer status. Metal failures are logged instead of silently removing the orb.
- Showing the orb and changing displays rechecks its position on screen.
